MapsApp
Levantar proyecto en Dev

1. Clonar repositorio
2. Instalar dependencias  npm i -D dotenv
3. Generar el '.env' basado en el '.env.template'
4. Ejecutar el comando 'npm run set-envs'
5. Añadir en angular.json la dependencia de maxbox para poder lanzarlo 
"allowedCommonJsDependencies": [
              "mapbox-gl" 
            ],
6. instalar mapas npm install --save mapbox-gl
